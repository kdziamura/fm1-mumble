# PLAY mode's REC: the keys played go into the selected character's take on the
# loop (2 bars at 120 BPM: 4 s), which plays them back pass after pass; the
# metronome counts the beats while recording; EDIT undoes a pass at a time.
wait 600
tap GLO
expect mode 1
# REC starts the loop and records; HERO has no line, so only the take sounds.
tap REC
expect recording 1
expect loop 1
expect metronome 8
wait 500
key 0 down
wait 400
key 0 up
wait 50
expect take 1
expect passes 1
wait 600
expect sounding 0
shot record-play.png
# The next pass: the note sounds again with no key held, then lets go.
wait 3100
expect sounding 1
wait 900
expect sounding 0
# Overdub, a chord this time: E, H and L together join the take as a new pass.
key 4 down
key 7 down
key 11 down
wait 300
expect sounding 1
key 4 up
key 7 up
key 11 up
wait 50
expect take 4
expect passes 2
# REC again stops recording (and the metronome); the take keeps playing.
tap REC

expect metronome 0
