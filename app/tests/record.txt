# SING mode: every character sings one note at a time, and the keys held are
# shared out among the choir. REC records what is sung into the loop (2 bars at
# 120 BPM: 4 s), played back pass after pass; the metronome counts the beats
# while recording; EDIT clears the selected character's notes, held the loop.
wait 600
turn ALGO 1
expect mode 1
# Alone, a character is a mono synth: the last key wins, and when it goes the
# one still held sounds again.
key 0 down
wait 100
key 2 down
wait 100
expect singing 1
expect sung 2
key 2 up
wait 100
expect singing 1
expect sung 0
key 0 up
wait 600
expect singing 0

key 14 down
wait 100
expect singing 3
expect sung 14
key 14 up
wait 100
expect singing 3
key 4 up
key 7 up
key 11 up
wait 300
expect singing 0
